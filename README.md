# WoHinDamit?

Smart Recycling Vienna
WoHinDamit? ist eine Webanwendung, die Nutzerinnen und Nutzern in Wien hilft, Gegenstände sinnvoll witeryuverwenden, yu reparieren, yu spenden oder richtig yu entsorgen.
