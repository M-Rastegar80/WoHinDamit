# WoHinDamit?

Smart Recycling Vienna
WoHinDamit? ist eine Webanwendung, die Nutzerinnen und Nutzern in Wien hilft, Gegenstände sinnvoll witer zu erwenden, zu reparieren, zu spenden oder richtig zu entsorgen.
